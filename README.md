# Sentiment Analysis Web App

This is a Flask-based NLP project using TextBlob.

## Features
- Sentiment analysis
- Subjectivity detection
- Token counting
- Simple UI

## Technologies
- Python
- Flask
- TextBlob
- Bootstrap

## Run Project
1. Install requirements:
   pip install -r requirements.txt

2. Run app:
   python app.py

3. Open browser:
   http://127.0.0.1:5000/
